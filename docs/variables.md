## omerfsen.aicr.aicr

| Variable | Type | Default | Description |
|---|---|---|---|
| `aicr_state` | str | `present` | `present` renders the bundle, then applies it (helmfile) or writes it to a GitOps checkout (argocd-helm). `absent` destroys the stack the helmfile deployer installed (`helmfile destroy` of the kept bundle). Helm keeps CRDs and namespaces. |
| `aicr_deployer` | str | `helmfile` | `helmfile` applies the bundle from this host with `helmfile apply`. `argocd-helm` writes an Argo CD Helm-chart bundle into `aicr_gitops_dir`; Argo CD applies it from Git. Nothing is applied from this host. |
| `aicr_gitops_dir` | path | `""` | With `argocd-helm`, the directory in a Git checkout that Argo CD watches. The role writes it but does not commit or push. |
| `aicr_kubeconfig` | path | `""` | Path of the cluster's admin kubeconfig on the target host. Required with the `helmfile` deployer. |
| `aicr_owner` | str | `root` | Owner of the files and binaries the role writes. |
| `aicr_group` | str | `root` | Group of the files and binaries the role writes. |
| `aicr_version` | str | `1.2.0` | aicr release. Change `aicr_sha256` with it. |
| `aicr_url` | str |  | Where the aicr archive is downloaded from; by default the GitHub release of `aicr_version` for the host's architecture. |
| `aicr_sha256` | dict |  | SHA-256 of the aicr archive per architecture (`amd64`, `arm64`), from the release's `aicr_checksums.txt`. |
| `aicr_helmfile_version` | str | `1.8.2` | helmfile release. Change `aicr_helmfile_sha256` with it. |
| `aicr_helmfile_url` | str |  | Where the helmfile archive is downloaded from; by default the GitHub release of `aicr_helmfile_version` for the host's architecture. |
| `aicr_helmfile_sha256` | dict |  | SHA-256 of the helmfile archive per architecture. |
| `aicr_helm_diff_version` | str | `3.15.15` | helm-diff plugin release. Change `aicr_helm_diff_sha256` with it. |
| `aicr_helm_diff_url` | str |  | Where the helm-diff archive is downloaded from; by default the GitHub release of `aicr_helm_diff_version` for the host's architecture. |
| `aicr_helm_diff_sha256` | dict |  | SHA-256 of the helm-diff archive per architecture. |
| `aicr_bin_dir` | path | `/usr/local/bin` | Where aicr and helmfile are installed. |
| `aicr_helm` | path | `/usr/local/bin/helm` | helm on the target host (Helm 3 or 4). The role does not install it. |
| `aicr_kubectl` | path | `/usr/local/bin/kubectl` | kubectl on the target host. |
| `aicr_helm_plugins_dir` | path | `/root/.local/share/helm/plugins` | Helm plugin directory of the user the role runs as. |
| `aicr_workdir` | path | `/var/lib/aicr` | Holds the downloads, the rendered AICRConfig, recipe and bundle, the kept bundle and the validation report. |
| `aicr_criteria` | dict | `{'service': 'nvke'}` | Recipe criteria, the `aicr recipe` flags as keys (`service`, `accelerator`, `intent`, `os`, `platform`, `nodes`). Only `service` is required. A combination AICR has no recipe for fails the run with AICR's own message. |
| `aicr_profile` | str | `""` | Optional recipe configuration profile, `name=value`. |
| `aicr_set` | list | `[]` | Scalar value overrides, `component:path=value`, as `aicr bundle --set`. |
| `aicr_set_json` | dict | `{}` | List or object value overrides, `component:path` to any value, as `aicr bundle --set-json`. |
| `aicr_scheduling` | dict | `{}` | `spec.bundle.scheduling` of the AICRConfig (node selectors, tolerations, storage class), passed through as is. |
| `aicr_apply` | bool | `True` | Apply the bundle with helmfile. Off renders it only. |
| `aicr_gpu_operator_timeout_minutes` | int | `30` | How long to wait for the GPU Operator's ClusterPolicy to be ready before validating. |
| `aicr_validate` | bool | `True` | Run `aicr validate` after the apply. |
| `aicr_validate_phases` | list | `['conformance']` | Validation phases (`deployment`, `conformance`, `performance`). AICR's nvke recipe declares conformance checks only. |
| `aicr_validate_skip_checks` | list | `[]` | Checks this cluster cannot satisfy; AICR reports them as skipped. |
